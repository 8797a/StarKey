# 星钥发卡（StarKey）

星钥发卡是一款基于 PHP 与 MySQL 开发，并接入 V免签个人免签约回调支付系统的自动发卡平台。

系统支持商品展示、微信与支付宝收款、V免签到账回调、卡密自动发放、订单查询、商品管理、卡密管理、订单管理及后台配置。

## 主要功能

- 数字商品展示与库存统计
- 微信、支付宝下单
- V免签异步支付回调
- 支付成功后自动分配卡密
- 订单状态与卡密查询
- 商品、订单和卡密后台管理
- 卡密批量导入
- 后台登录保护和 CSRF 防护

## 配置

复制 `includes/config.example.php` 为 `includes/config.php`，填写数据库和 V免签配置。请勿将包含真实数据库密码、V免签地址、密钥或个人收款信息的 `includes/config.php` 提交到公开仓库。

> 正式使用前请修改默认管理员信息，并根据实际 V免签服务端协议完善支付回调校验。
